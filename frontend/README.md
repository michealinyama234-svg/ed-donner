# Kanban Web App

A client-rendered single-board Kanban project management application built with Next.js, TypeScript, Tailwind CSS, and @dnd-kit.

## Features

- Single board with 5 fixed columns (renameable)
- Card creation with title and details
- Card deletion
- Drag and drop card movement between columns
- Initial dummy data populated on load
- Client-only in-memory state with zero persistence

## Getting Started

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Run unit tests:
```bash
npm run test
```

Run end-to-end tests:
```bash
npx playwright test
```
